# Создание компонента

Применить ветку нового компонента/варианта. Если источник или существенный контракт не определён, сначала уточнить его; новый компонент не проектировать скрыто под видом реализации.

Прочитать [вход в задачу](../../../docs/environment/workflows/task-start.md), затем [рабочую директиву](../../../docs/environment/workflows/component.md). Они подключают применимые стандарты и общий порядок проверки. Пути ссылок считаются от этого файла, команды выполняются из корня выбранной рабочей копии.
