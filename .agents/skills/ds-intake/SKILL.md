# Уточнение задачи

Извлечь известные вводные и выяснить только существенные пробелы. Выход — понятная постановка и выбранный следующий маршрут, а не реализация по предположениям.

Прочитать [вход в задачу](../../../docs/environment/workflows/task-start.md), затем [рабочую директиву](../../../docs/environment/workflows/intake.md). Они подключают применимые стандарты и общий порядок проверки. Пути ссылок считаются от этого файла, команды выполняются из корня выбранной рабочей копии.
