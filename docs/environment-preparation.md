## 4. Известные вопросы до изменения среды

1. `.nvmrc` выбирает Node 20 и используется CI; Style Dictionary 5.4.0 в lockfile требует Node ≥22. Локальные проверки проходят на Node 22.17.0; декларации версий и чистый запуск CI требуют отдельного решения в новой ветке.
2. `CLAUDE.md` остаётся действующим контрактом. Его сведения о версиях и отдельные требования расходятся с текущими конфигурациями; противоречия нужно внести в карту переноса до замены правил.
3. Общие настройки Git и агентских клиентов не изолируются одним worktree. Любые последующие изменения этих настроек должны учитывать исходную рабочую папку.
4. Лицензирование, границы переноса и дальнейшее обновление частей Work Environment уточняются перед интеграцией. Частный репозиторий не становится runtime-зависимостью публичной DS.

При утрате основной папки сначала восстановить репозиторий из GitHub или `repository.bundle`, затем нужные локальные материалы из архива.
