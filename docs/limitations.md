# Границы возможностей

- Рабочая платформа — React web; разработка выполняется на Node 22. Другие платформы и клиенты требуют отдельного согласования.
- env:route --request даёт подсказку по ключевым словам. Ведущий проверяет контекст, выбирает проект и проводит достаточный бриф.
- create создаёт контейнер проекта и Discovery; install-tooling копирует инструменты процесса. Полный React starter не генерируется автоматически. [Project setup](../directives/project-setup.md) — процедура ведущего после брифа и выбора доступного версионированного шаблона; наличие директивы не означает наличие готового каталога starter-шаблонов.
- env:primitives поддерживает JSON $type/$value с конечными HEX, number, string/fontFamily/fontWeight, boolean. Составные значения и aliases только показываются. Произвольные текст/файлы нормализует ведущий; шрифты, Figma и генераторы инструмент сам не подключает. Семантические файлы не изменяются.
- Автоматический полный граф влияния diff и динамических токенов не реализован. Проверки выбираются по изменению и реальным потребителям.
- Скиллы и роли читаются явно из skills/ и agents/. Наличие TOML не доказывает запуск отдельного исполнителя или независимый review. Доступность делегирования и лимиты задаёт клиент; [незакрытые проверки](../BACKLOG.md).
- Набор инструментов сам по себе не доказывает полноценную готовность дизайн-системы. Передача проверяется установкой, сборкой, тестами и consumer в самостоятельной копии.
- Storybook build и Code Connect parse не подтверждают визуальный паритет, ручную доступность или публикацию. Внешние записи и Git/publish выполняются по соответствующему поручению.
- Иконки/графики исключены до нового явного поручения. Предметные решения и исключения конкретного проекта хранятся внутри него.

- env:project export поддерживает кодовый проект с package/lock/src/Storybook; отдельного Figma-only адаптера нет. Для Figma-only передаются целевая библиотека и проектные материалы по [Figma-поставке](../directives/figma-delivery.md); офлайн-файл требует реального доступного экспорта Figma.
