# Руководство по среде

Design System Developer работает самостоятельно либо как модуль Work Environment верхнего уровня. Корень GitHub-репозитория содержит разработчик; React-библиотека AI-PDP-DS находится в projects/ai-pdp-ds. Корневой private package не публикуется в npm.

## Установка и запуск

Нужны Git, Node 22 и npm 10.9+. Из клона выполнить npm ci, затем npm run env:check, npm test, npm run lint и npm run format:check. Локальные toolchains, node_modules и приватные env не входят в Git. При nvm выполнить nvm use. Вложенный пример устанавливается отдельно: cd projects/ai-pdp-ds, npm ci, npm run tokens:build, npm run storybook. Адрес выводится сервером; стандартный порт 6006. Локальная работа не требует Figma/Chromatic/npm credentials.

## Кто управляет процессом

Основной агент читает [AGENTS](../AGENTS.md) и [PROCESS](../PROCESS.md). В Work Environment явная команда «Запусти разработчик дизайн-систем» передаёт управление этим же файлам. В отдельном клоне достаточно открыть корень и указать агенту AGENTS.md. Автоматическая регистрация клиентских скиллов/ролей не требуется. Скилл выбирает процедуру; отдельный агент выполняет ограниченную подзадачу. Доступность конкретных инструментов определяется клиентом.

## Маршруты

Новая система: intake → контейнер проекта → бриф → необходимое исследование → выбор версии фундамента → техническое развёртывание → план примитивов → компоненты → выбранная поставка → проверка → review → фактическая приёмка. Это условный маршрут: ремонт не повторяет весь Discovery, аудит не реализует исправления.

Из корня: npm run env:project -- create bank-ds --name "Bank DS" создаёт только Discovery-контейнер. После брифа ведущий разворачивает выбранный технический шаблон; готового универсального React starter-генератора нет. npm run env:project -- install-tooling bank-ds копирует инструменты процесса, не библиотеку.

Компонент: npm run env:task -- init add-input --project bank-ds --component input. Один принятый component-specs/input/spec.md предшествует реализации; следующая задача сохраняет общий Spec. Продолжение: npm run env:task -- resume add-input --project bank-ds. Текущий STATE живёт в журнале задачи; refresh не переисполняет проверки и не подтверждает Spec.

Примитивы: npm run env:primitives -- matrix --project bank-ds; затем plan с --input product-discovery/primitive-request.json. Apply требует fingerprint показанного плана и note реального согласования. Меняются конечные значения, семантические ключи/aliases сохраняются. Шрифты произвольные: ресурсы заказчика либо Google Fonts по указанию.

Поставка storybook вызывает кодовую ветку без Figma; figma не требует React/Storybook; both проверяет обе поверхности и паритет. Кодовый export CLI требует package/lock/src/Storybook и не является Figma-only экспортом.

## Где находятся результаты

Все материалы системы с начала работы находятся в projects/<id>. Общий brief, исследования, решения и общесистемные задачи — product-discovery; единственный контракт компонента и его задачи — component-specs/<id>; реализация — src; источники значений — tokens; документация потребителя — docs. Кодовые проекты имеют свои package/lock, Storybook, scripts и CI. Нет npm workspaces или parent imports. Продуктовые журналы/история передаются с системой; временные задачи самого разработчика очищаются после работы, будущие улучшения учитываются в BACKLOG.

## Проверки и передача

Корневой CI проверяет разработчик и отдельно полный quality:report примера. Вложенные workflows не запускаются GitHub из родительского репозитория; они предназначены для отдельного репозитория библиотеки. Проверка пакета включает архив, установку consumer, types, ESM/CJS, SSR и CSS. Сборка не подтверждает весь визуальный паритет или ручную доступность.

Передача кода: npm run env:project -- export ai-pdp-ds --out <новая-папка-вне-разработчика>. Export исключает Git, секреты, зависимости и outputs и создаёт manifest с хешами. Получатель выполняет собственную установку и проверки. Git push, npm/Chromatic/Figma publish — самостоятельные явно порученные действия. Разработчики иконок и графиков не включены.
