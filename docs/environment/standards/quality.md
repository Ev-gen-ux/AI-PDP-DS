# Проверки и доказательства качества

Перед commit выполнить npm run format и npm run format:check. Непройденный format:check запрещает commit: FORMAT VIOLATION: run npm run format and npm run format:check before commit. Перед PR/commit пройти применимые typecheck, lint, test; lint без warnings. Остальные проверки выбирать по области изменения и действующим workflows.

Для компонента обязательны token-first, строгие props/exports, transient props, type="button", focus-visible и остальные применимые стандарты. Не обходить gates для получения зелёного отчёта. Type Safety нарушение исправляется до зависимой реализации.

Definition of Done: все согласованные варианты/состояния, stories и API docs, Spec Verification, применимые fidelity/engineering/ThemeCheck/mapping проверки, оценка версии/changeset и review. Для локального ремонта применяется масштаб из tasks, но требования к затронутому поведению сохраняются.

Использовать существующий quality:report: tokens:build, typecheck, lint, format:check, test:coverage, test:tooling, build, package:check, storybook:build, figma:check. Не создавать параллельный кабинет. CI-артефакты и локальный JSON — доказательства конкретного запуска, не обещание качества всех сценариев.

Доказательство содержит входную ревизию/хеш, команду либо метод ручного review, результат, дату и ограничения. Разделять:

- корректность структуры инструкций/схем;
- успешность выполнения задачи агентом;
- техническое и визуальное качество компонента;
- принятие владельцем конкретной версии результата.

Не выдавать parse за публикацию, сборку Storybook за interaction/visual tests, наличие schema за вызов валидатора. Отсутствие комментария не является approval. Не выполненные ручные или внешние проверки отмечаются как не выполненные.

Проверки среды и навыков вводятся последующими этапами: ошибки маршрутизации, пропущенный стандарт, сохранность ручной ревизии, возобновление, отсутствие инструмента, отрицательные вызовы. Сравнения candidate/baseline используют одинаковые задачи, модель, инструменты, разрешения и зависимости; окончательный набор не используется для подбора инструкций.
