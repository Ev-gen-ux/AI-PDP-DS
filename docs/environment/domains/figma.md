# Подсреда figma

Перед работой прочитать [tasks](../standards/tasks.md), [quality](../standards/quality.md) и применимые стандарты:

- [figma](../standards/figma.md)
- [tokens](../standards/tokens.md)
- [components](../standards/components.md)
- [documentation](../standards/documentation.md)
- [governance](../standards/governance.md)

Объём чтения определяется затронутой поставкой. Для аудита результат — findings, для изменения — артефакт и доказательства с ревизией. Переход в соседнюю подсреду сохраняет единый scope/Spec и требует её стандарты.

Инструменты и фактические возможности читать из package.json и существующих scripts; новый workflow/навык не считается реализованным по одному индексу.
