# Результат P0.4

Дата: 25 ноября 2026 года. Реализовано локальное состояние задач и безопасное возобновление по принятому плану.

## Поставка

- `scripts/environment/task-state.js` и `npm run env:task` — init, resume, check, update, refresh и ref.
- [Схема](schemas/task-state.schema.json) реально используется runtime-валидатором. Дополнительно проверяются пути, статусы, привязки источников, stale evidence и запись приёмки.
- Состояние хранится в `.local/tasks/<id>/state.json`, точные прежние версии — в history/. Неизвестные требования остаются null; Spec хранится ссылкой и SHA-256.
- Init не перезаписывает существующие задачи. Записи используют lock, ожидаемый SHA-256 state, историю и атомарную замену файла.
- Resume/check не исправляют и не сокращают данные. Изменённые входы и артефакты видны явно; refresh не переатрибутирует старые доказательства.
- Accepted требует записанную приёмку для текущего fingerprint и актуальные passing evidence. Это техническая проверка согласованности записей, а не удостоверение личности владельца или полноты всех предметных проверок.

Процедура и примеры — [task-state](workflows/task-state.md). Для машинного JSON удобно использовать прямой запуск Node либо `npm run --silent env:task -- ...`.

## Проверки

24 сценария нового tooling: повторная инициализация, неизвестные поля и версии, неполные вводные, безопасные пути, символические ссылки, восстановление в другом процессе/подпапке, ручные изменения, stale tokens, точная история, статусы/блокировки, текущие доказательства/приёмка, изменённые и исчезнувшие Spec/артефакты, смена Git HEAD, writer lock, два конкурентных процесса и неподдержанный ключ схемы. Тесты входят в существующий test:tooling и quality:report.

На реальной локальной записи `environment-p04` проверены init, продвижение discovery → ready → implementation и check. Приёмка владельцем не создавалась; запись и результаты в `.local/` не публикуются.

[Полный контрольный прогон](P04-quality-2026-11-25.json): 10/10 PASS на Node 22.17.0, 175/175 тестов компонентов и 44/44 tooling-теста, включая 24 новых. Прогон относится к 54324fb с локальными изменениями P0.4. Новых зависимостей не установлено; реализация компонентов, токены, публичные экспорты и workflows публикации не менялись.

## Границы

Fingerprint охватывает объявленные входы и Git HEAD; не перечисленные зависимости и произвольные незакоммиченные файлы не сканируются автоматически. Lock координирует CLI-писателей; гарантии для произвольного внешнего редактора и автоматическое восстановление после сбоя процесса не заявлены. История не является полной резервной копией исходников.

Runtime поддерживает ограниченные ключевые слова поставляемой JSON Schema и останавливается при неизвестных. Он не является универсальным JSON Schema engine. Проверки не исполняют строки method и не доказывают реальное выполнение описанного review.
