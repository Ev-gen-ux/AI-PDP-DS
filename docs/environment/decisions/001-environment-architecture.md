# Решение 001 об архитектуре среды

Статус: принято владельцем в этой сессии ответом «согласовано» на результат P0.2, ревизия проекта f53590c. Дата фиксации: 20 ноября 2026 года.

Приняты [структура и решения D1–D10](../../environment-architecture-proposal.md). Перенос начинается с P0.3: общего контракта, стандартов и входов агентов. Нормативные источники остаются обычными файлами; процедуры, инструменты и регистрация навыков вводятся отдельными порциями.

- D1: соразмерные маршруты docs/audit, ремонт существующего компонента, новый/визуально изменённый компонент. Детали в стандарте tasks.
- D2: Figma-first по умолчанию; code-first требует явно согласованных Spec и приёмки.
- D3: выбран профиль Node 22; синхронизация .nvmrc, engines и CI — отдельный технический коммит. Текущие декларации не меняются этим решением автоматически.
- D4: обязательный AllVariants удаляется из шаблона PR; Default и применимые состояния сохраняются.
- D5: IconSize остаётся 16/24, некорректный пример не переносится в активные инструкции. Выбор и реализация fallback рассматриваются отдельно; действующее требование meta пока сохраняется.
- D6: правило четырёх файлов сохраняется до конкретизации согласованных исключений; решение не разрешает удалять mappings.
- D7: CODEOWNERS и фактическая защита ветки проверяются отдельно, без обещания автоматической гарантии approval.
- D8: источник фактического каталога — код/экспорты/stories; зрелость и приёмка имеют отдельные доказательства. Генератор каталога — последующий этап.
- D9: имя и версии берутся из package.json/lockfile; исправление примера не расширяет поддержку фреймворков.
- D10: рабочие workflows и явно запускаемые крупные директивы имеют разные роли. Продуктовый конвейер Work Environment адаптируется к DS.

Приёмка архитектуры не означает, что все будущие инструменты уже реализованы, публикации разрешены или все компоненты прошли ручной review. Откат по [документу подготовки](../../environment-preparation.md).
