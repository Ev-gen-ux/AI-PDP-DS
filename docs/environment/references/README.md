# Справка и архив

Эта папка содержит пояснения и исторические снимки, не второй активный контракт. Общий вход — AGENTS.md в корне; обязательные требования находятся в standards/.

legacy-claude.md сохраняет точный старый контракт после предупредительного заголовка. Старые примеры могут содержать размер иконки 20, старое имя пакета и устаревшие версии. Они не используются как актуальные образцы реализации. Исходные строки шести документов также сохранены в docs/environment-rule-map.json на ревизии f53590c.

Исторические инциденты Figma и старый список компонентов проверяются по текущим источникам перед применением. Действующее требование исправлять источник, выполнять sync и не создавать ошибочные aliases перенесено в стандарт tokens.

[legacy-sources.json](legacy-sources.json) хранит точные исходные тексты и SHA-256 четырёх заменённых документов. Читаемая Markdown-копия legacy-cursor.md нормализует завершающие пробелы исторической строки версии; точные байты сохранены в JSON. Эти файлы не являются активными инструкциями.
