# Подключение к проекту

Канонический вход — [AGENTS.md](../../AGENTS.md). Версии, имя пакета и команды читать из package.json/lockfile и .nvmrc; ориентиры в исторических документах не заменяют конфигурацию.

## Локальная работа

Из корня выбранной рабочей копии: npm ci, затем npm run tokens:build. Сборка библиотеки — npm run build, Storybook — npm run storybook (порт 6006). Документация — docs/Introduction.mdx. Установку выполнять с учётом фактических требований зависимостей.

Открытое техническое действие D3: .nvmrc=20, Style Dictionary 5.4.0 требует Node ≥22, отдельный npm-publish workflow использует 24. Проверенный baseline подготовки — Node 22.17.0. Принят профиль Node 22, но синхронизация деклараций выполняется отдельным коммитом. Перед установкой проверять фактическую версию; зелёный CI на 20 не устраняет расхождение требований.

Обычные проверки — [quality](standards/quality.md). tokens:pull используется по задаче, а tokens:push и публикация — только в разрешённых сценариях. Не начинать заново завершённые этапы проекта. Существующие Stack/Cluster/Grid, компоненты, токены, stories и Foundations изучаются до разработки нового.

Каталог доступных компонентов сверять с src/index.ts, src/components, src/layouts и stories. component_list.md игнорируется Git и не гарантирован в checkout; исторические статусы не являются доказательствами зрелости.

## Агентские клиенты и интеграции

Codex читает корневой AGENTS.md. CLAUDE.md направляет Claude к тому же контракту; Cursor использует общий вход и этот onboarding. Если клиент не загружает вход автоматически, открыть его явно. Реальную загрузку и область инструкций проверять в используемой версии клиента; перенос текста не является проверкой совместимости.

Девять канонических навыков P0.5 находятся в .agents/skills; выбор и ссылки — в [карте навыков](skills.md). Их можно прочитать явно вместе с рабочей директивой. Обязательные стандарты применяются независимо от навыка. Автоматическое обнаружение/вызов в новых сессиях и адаптеры других клиентов ещё требуют P1.2; глобальная установка и дубли в .claude/.cursor не выполнялись.

Figma MCP подключается через клиент с поддержанным endpoint и OAuth; наличие инструкции не устанавливает сервер. Для файловой конфигурации и токенов использовать локальное окружение, не коммитить секреты. Настройки доступа и branch protection выполняются отдельно владельцем по явному поручению. Актуальные права инструментов проверяются по их схеме.

Источники проекта: GitHub Ev-gen-ux/AI-PDP-DS и Figma i7T3ru2M0SyXgJeTda8f43. [Подготовка, worktree и возврат](../environment-preparation.md) описывают конкретную рабочую базу перестройки.

## Состояние длительной задачи

`npm run env:task -- --help` и [процедура состояния](workflows/task-state.md) описывают локальный init/resume/check/update/refresh/ref. Новая сессия сначала читает resume и проверяет stale/problems; чтение само не исправляет состояние.
