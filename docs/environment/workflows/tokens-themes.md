# Изменение токенов и тем

После [входа](task-start.md) открыть [индекс tokens](../domains/tokens.md) и его стандарты. Различить исправление исходника, разрешённую синхронизацию и изменение потребления существующего токена.

1. Найти каноническое имя, исходное значение/режим и зависимости в tokens/, генераторе, теме и потребителях. Прочитать доступные операции в `scripts/figma-tokens-pull.js` и `scripts/figma-tokens-push.js`; название команды не гарантирует read-only поведение.
2. Сравнить Figma и файловый источник, установить направление порученной синхронизации. Конфликт или новый семантический смысл представить для решения, не маскировать alias/хардкодом. Для изменения Figma проверить полномочия и доступ до записи.
3. Изменить согласованный исходник, выполнить `npm run tokens:build`, сравнить diff и фактические resolved values в применимых modes. Производные файлы не исправлять вручную. Если они игнорируются Git, проверить содержимое и потребителей отдельно: отсутствие tracked diff не доказывает отсутствие изменений.
4. Проверить затронутые компоненты, переключение тем и Foundations; при необходимости обновить документацию и Figma mapping. Отделить локальную генерацию от подтверждённой внешней синхронизации.

Выход: источник и причина изменения, затронутые режимы/потребители, результат генерации и проверок. Закончить по [общей передаче](verify-deliver.md). Автоматически не запускать tokens:push, установку или смену формата данных.
