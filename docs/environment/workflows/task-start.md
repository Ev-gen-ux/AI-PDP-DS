# Вход в задачу

Общая рабочая директива для навыков. Прочитать [контракт](../../../AGENTS.md), [tasks](../standards/tasks.md) и [quality](../standards/quality.md); выбрать предметный индекс по таблице контракта и открыть применимые стандарты. Навык добавляет процедуру, а не заменяет обязательный маршрут.

1. Установить корень нужной рабочей копии, текущую ветку, ревизию и незакоммиченные изменения. Чужие изменения сохранить; существующую ветку порученной работы не заменять новой при каждом вызове навыка.
2. Прочитать запрос, существующий Spec/решения и состояние длительной задачи. Если ID известен, выполнить `npm run --silent env:task -- resume <id>`, разобрать stale/problems и изменения входов перед обновлением. При неизвестном ID найти подходящую запись в `.local/tasks/` по контексту; не возобновлять произвольную задачу и не перезаписывать её. Init нужен только для новой длительной задачи по [процедуре состояния](task-state.md). Простая задача может обойтись краткой записью.
3. Кратко определить действие, объект, платформу, поставку, границы и критерий завершения. Извлечь уже известное из источников; вопросы из закрытого брифа не задавать повторно. Разделить блокирующие вопросы для зависимой работы и неблокирующие для независимой.
4. Выбрать [маршрут](../skills.md) по намерению и фактическому влиянию. Проверить доступность требуемых инструментов/источников до обещания результата. Зависимую от отсутствующего инструмента часть отметить; независимую авторизованную работу продолжать.

Scope не расширяется из-за перехода в соседнюю подсреду. Для icons/charts прочитать соответствующий индекс; новые предметные разработчики ещё не интегрированы. Не вызывать приватную среду, устанавливать генератор или переносить модули автоматически.

При смене входов сначала прочитать diff и сохранить ручные решения; `refresh` не является подтверждением старых проверок. Данные задачи остаются в `.local/`; документация содержит только предназначенные для репозитория решения и обезличенные доказательства.
