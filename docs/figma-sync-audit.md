## Токены: синхронизация с Figma

| Направление              | Механизм                                               | Замечание                                                                                       |
| ------------------------ | ------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| **Figma → репозиторий**  | `npm run tokens:pull` (`scripts/figma-tokens-pull.js`) | Требуются `FIGMA_ACCESS_TOKEN`, `FIGMA_FILE_KEY` в `.env`.                                      |
| **Репозиторий → сборка** | `npm run tokens:build`                                 | Генерирует `src/theme/tokens.ts` (в `.gitignore`), CSS variables, **`dist/figma.tokens.json`**. |
| **Репозиторий → Figma**  | `npm run tokens:push`                                  | Обратная выгрузка переменных; см. `scripts/figma-tokens-push.js`.                               |

### Контроль расхождений токенов (офлайн)

1. После `tokens:pull` сравнить diff в `tokens/**/*.json` с ожиданиями дизайна.
2. Учитывать известные опечатки имён в Figma из **CLAUDE.md §16** (чтобы не дублировать баги в коде).
3. В **palette / spacers** сверить «исторические» несоответствия имени и значения — в текущем `tokens/primitives/spacers.json` ключ `80` не найден; если переменная живёт только в Figma, она появится после pull.

## Рекомендуемые следующие шаги

1. Запустить `npm run figma:publish` локально (с токеном и доступом Code Connect) и проверить маппинг Tab / TabGroup.
2. Выполнить `npm run tokens:pull` при валидных секретах и просмотреть diff.
3. Периодически повторять `get_metadata` по мастер-узлам при изменениях в Figma.
