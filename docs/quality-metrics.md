### Инциденты и пробелы: Counter (2026-05-02)

Зафиксировано по сессии сверки токенов с Figma, правке тёмной темы и геометрии одиночной цифры.

#### Что было непонятно или двусмысленно

| Зона                      | Неоднозначность                                                                                                                                                                                                                                       | Как проявилось                                                                                                                                     |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Семантика vs Figma**    | В репозитории dark-тема для `counter` расходилась с актуальной таблицей переменных в Figma (после перепривязки примитивов), без единого артефакта «снимок таблицы» в PR                                                                               | Пока пользователь не прислал скриншот токенов, опорой оставались только JSON и догадки; **background calm** и **label loud** в dark были неверными |
| **Numeric map в спеке**   | В `counter-component-spec.md` для XS single primary было указано ненулевое padding (`xxsCompact` / `compact`); не сказано явно, что при **одной цифре** контейнер должен быть **квадратом 1:1** под `borderRadius.rounded`, иначе визуально «капсула» | Реализация повторила таблицу спеки; пользователь ожидал **круг** для единичных значений                                                            |
| **Оси padding в таблице** | Обозначения «×» и «y» в строке padding легко перепутать с порядком в CSS `padding: A B` (сначала вертикаль, потом горизонталь)                                                                                                                        | Даже при чтении спеки несоответствие «круг vs pill» не выводилось однозначно без визуального эталона                                               |

#### Ошибки / расхождения (симптом → причина → что сделано)

| Симптом                                                     | Причина                                                                                                         | Реакция                                                                                               |
| ----------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Primary XS, одна цифра — вытянутый по горизонтали контейнер | Горизонтальный padding (`compact` = 8px с каждой стороны) при высоте 16px                                       | Убрано различие primary/secondary для bucket `single` на XS: **16×16**, `padding: 0`; спека обновлена |
| Dark: фон «calm» и текст «loud» не совпадали с макетом      | Устаревшие алиасы в `colors.dark-theme.json` (`neutral.700` / `neutral.100` вместо актуальных **500** / **50**) | Исправлены токены; `npm run tokens:build`                                                             |
| Light: «loud» label темнее ожидаемого (раньше в сессии)     | В семантике светлой темы для `counter.label.loud` использовался более тёмный шаг палитры относительно Figma     | Выровнено на **`neutral.700`** по макету                                                              |

#### Пробелы процесса (рекомендации)

| Пробел                                                                             | Рекомендация                                                                                                                |
| ---------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Нет автоматической проверки «токен в JSON = строка в Figma Variables»              | После изменений в Figma — явный чеклист или скрин/экспорт таблицы в описание задачи или в Component Spec → **Verification** |
| Спека фиксировала размеры/padding без явного **инварианта формы** для single-digit | В Hard Constraints или Numeric map добавить: при `bucket === single` ширина = высота (круг/скруглённый квадрат)             |
| Визуальные ожидания («круг») не попадали в gates                                   | Для бейджей с `borderRadius.rounded` — минимум одна story/скрин «single digit» в ThemeCheck или визуальный тест             |

**Интерпретация:** сбоев CI и `tsc` не было; проблемы были **дрейфом семантики относительно Figma** и **неполной спецификацией геометрии** для одиночного символа. Источник правды после правок — таблица токенов Counter в Figma + обновлённый `counter-component-spec.md`.
