### Инциденты и пробелы: InputDate — кастомный плейсхолдер и нативный ввод (2026-05-03)

Зафиксировано по сессии: визуальный баг в Storybook — подсказка **не скрывалась** при фокусе и пошаговом вводе в `input type="date"`, исчезала только после полной даты и часто воспринималась как «после снятия фокуса».

#### Ошибки / симптомы (симптом → причина → что сделано)

| Симптом                                                                                            | Причина                                                                                                                                                                                                     | Реакция                                                                                                                                                      |
| -------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Текст плейсхолдера (**«дд.мм.гггг»**) остаётся под/над сегментами ввода при фокусе и неполной дате | Оверлей показывался при **`!hasValue`**, а **`hasValue`** = непустой **`value`**; у нативного date **`value`** часто **`''`**, пока дата не собрана целиком, при этом браузер уже отображает частичный ввод | Состояние **`inputFocused`** (только **`onFocus`/`onBlur`** самого input, не кнопки календаря); оверлей при **`!hasValue && !inputFocused`**                 |
| Ввод цифр плохо читается вместе с оверлеем                                                         | При пустом **`value`** у нативного поля задан **`color: transparent`**, чтобы был виден только кастомный плейсхолдер; при фокусе без финального **`value`** текст оставался прозрачным относительно задумки | Цвет текста значения, если **`hasValue` или `inputFocused`** (иначе `transparent`); caret по-прежнему видимый                                                |
| Регресс не выявлен автотестами до репорта                                                          | Тесты проверяли наличие плейсхолдера при пустом поле, но не сценарий **focus → оверлей исчезает**                                                                                                           | Тест **`hides custom placeholder while the date input is focused`**: есть текст → **`focus`** → **`queryByText`** плейсхолдера нет → **`blur`** → снова есть |

#### Чего не хватало (процесс / продукт)

| Пробел                                                                                  | Рекомендация                                                                                                                                                                       |
| --------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| В **component spec** InputDate не зафиксирована модель «fake placeholder + native date» | Явно: правила скрытия оверлея (**пустое value + нет фокуса на input**) и отдельно поведение при **disabled** / controlled **`value`**                                              |
| **Component Fidelity / Storybook** для story **Focus**                                  | После фикса прогнать ручной сценарий: пустое поле → клик в input → убедиться, что маска/сегменты не перекрываются подсказкой                                                       |
| Путаница **`value`** DOM vs визуальное «частично введено»                               | В документации пропсов кратко: нативный date не гарантирует непустой **`value`** до валидной даты; кастомный UI не должен опираться только на **`value.length`** для скрытия маски |

**Интерпретация:** ошибка **UX/визуальная**, не падение CI; корень — **смешение двух слоёв** (оверлей + нативный контроль) и условие видимости, завязанное только на **финальное** значение. Урок: для обёрток над **`type="date"`** с кастомным плейсхолдером в чеклисте — **фокус** и **частичный ввод** так же важны, как **commit** даты.
