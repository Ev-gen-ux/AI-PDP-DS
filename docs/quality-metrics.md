Зафиксировано по сессии сверки токенов с Figma, правке тёмной темы и геометрии одиночной цифры.

#### Что было непонятно или двусмысленно

| Зона                      | Неоднозначность                                                                                                                                                                                                                                       | Как проявилось                                                                                                                                     |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Семантика vs Figma**    | В репозитории dark-тема для `counter` расходилась с актуальной таблицей переменных в Figma (после перепривязки примитивов), без единого артефакта «снимок таблицы» в PR                                                                               | Пока пользователь не прислал скриншот токенов, опорой оставались только JSON и догадки; **background calm** и **label loud** в dark были неверными |

| **Оси padding в таблице** | Обозначения «×» и «y» в строке padding легко перепутать с порядком в CSS `padding: A B` (сначала вертикаль, потом горизонталь)                                                                                                                        | Даже при чтении спеки несоответствие «круг vs pill» не выводилось однозначно без визуального эталона                                               |

| Симптом                                                     | Причина                                                                                                         | Реакция                                                                                               |

| Light: «loud» label темнее ожидаемого (раньше в сессии)     | В семантике светлой темы для `counter.label.loud` использовался более тёмный шаг палитры относительно Figma     | Выровнено на **`neutral.700`** по макету                                                              |

#### Пробелы процесса (рекомендации)

| Пробел                                                                             | Рекомендация                                                                                                                |

### Инциденты и пробелы: Divider — вертикаль в Storybook (2026-05-02)

Зафиксировано по сессии: разделитель в **вертикальной** ориентации в превью Storybook **не был виден** (пустой canvas), при этом автоматические gates оставались зелёными.

#### Ошибки / симптомы (симптом → причина → что сделано)

| Симптом                                                                    | Причина                                                                                                                                                                                           | Реакция                                                                                                                                                                        |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| В Storybook при `orientation="vertical"` линия не отображается             | У элемента задана только **ширина** (`1px` через токен толщины), **высота** в обычном блочном потоке не задана и не наследуется — для пустого `div` без контента итоговая **computed height = 0** | В `Divider.tsx` для вертикали: `min-height: theme.spacing.height.xSmall`; в flex-строке со `align-items: stretch` линия по-прежнему растягивается выше минимума                |
| Тот же симптом мог проявляться в **Default** story даже после `min-height` | Демо рисовало вертикальный разделитель **вне** контекста flex-ряда с явной высотой родителя — визуально «ничего нет» или нечитабельно                                                             | В `Divider.stories.tsx` для вертикали в Default: обёртка `display: flex`, `flexDirection: 'row'`, `alignItems: 'stretch'`, заданная `height`, контент слева / Divider / справа |
| Тесты и CI не ловили дефект                                                | Юнит-тесты проверяют разметку/роли, но не **визуальное** наличие линии (не assert на `getBoundingClientRect().height` для vertical)                                                               | Опционально: в тесте для `orientation="vertical"` проверять `height > 0` после рендера в контейнере с известной высотой                                                        |

#### Чего не хватало (процесс / продукт)

| Зона                        | Пробел                                                                                                                                                                                   | Рекомендация                                                                                                                                                               |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Геометрия в спеке**       | В Numeric map было сказано «верт.: высота flex-родителя», но не зафиксирован **инвариант**: без flex/stretch или без `min-height` пустой вертикальный разделитель даёт **0px** по высоте | В `divider-component-spec.md` (и при новых компонентах-«линиях») явно: вертикаль — `min-height` из токена **или** обязательный родитель flex-row + `stretch` + высота ряда |
| **Component Fidelity Gate** | Не пройден **Pre-Story Visual Parity** для комбинации `orientation=vertical` до сдачи: пустой canvas не был замечен                                                                      | Чеклист перед PR: открыть **Default** и демо вертикали в Storybook, убедиться что линия видна в light/dark                                                                 |
| **Stories как контракт**    | Первая интерактивная story не отражала **минимальный реалистичный layout** для вертикали (как в продукте — между двумя колонками в ряд)                                                  | Для одномерных компонентов (divider, rule) в паттерне stories закрепить: вертикаль только внутри flex/grid с заданной осью                                                 |
| **Автотесты vs визуал**     | Зелёный `npm run test` не гарантирует отсутствие «невидимого» UI                                                                                                                         | Для критичных ориентаций — минимальный assert на размеры или визуальный регресс (Chromatic и т.п.)                                                                         |

**Интерпретация:** это **не** ошибка TypeScript/ESLint; корень — **CSS-бокс-модель** (пустой блок без высоты) и **недостаточная проверка Storybook** для вертикального сценария. Урок: для компонентов с осью `horizontal | vertical` обязательно верифицировать **обе** оси в превью и в спецификации (numeric + hard constraints).
