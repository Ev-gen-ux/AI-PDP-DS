# Вход Cursor в AI-PDP-DS

Перед работой прочитать [AGENTS.md](AGENTS.md) и перейти по маршруту задачи к обязательным стандартам. Общие требования не дублируются в этом адаптере.

Настройка, версии и запуск: [onboarding](docs/environment/onboarding.md). Если текущий клиент не обнаруживает общий контракт автоматически, открыть его явно. Подключение skills/hooks проверяется отдельно, глобальные настройки не меняются автоматически.

Статус перестройки и возврат: [подготовка](docs/environment-preparation.md), [план](docs/environment-rebuild-plan.md). Старые подсказки о версиях/бэклоге сохранены в историческом снимке карты; текущие факты читаются из исходников.
