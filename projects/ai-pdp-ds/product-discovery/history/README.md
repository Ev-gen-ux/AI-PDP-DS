# История исходной системы

[index.json](index.json) связывает исходные пути с сохранёнными файлами и SHA256. JSON/log-файлы и прежние state.json в tasks — неизменённые исторические артефакты, а не второй активный источник состояния. Их старые абсолютные пути/ссылки описывают исходную машину и версию.

[Приёмка ядра](evidence/core-acceptance.json) · [Отмена Combobox](evidence/ambiguous-request-combobox-acceptance.json). Снимки содержат только прежние результаты; повторный PASS и approval новой версии не назначены. Текущее состояние переноса находится в журнале Discovery. Ручной component-inventory.md — прежний каталог, не подтверждение текущей готовности.
